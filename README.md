# Ethiopia Financial Inclusion Forecast

This repository contains a data and modeling pipeline to forecast financial inclusion indicators in Ethiopia, including a lightweight dashboard for exploring results.

## Project structure

- `data/raw/`: Starter datasets, including unified input data and reference codes.
- `data/processed/`: Analysis-ready, cleaned, and feature-engineered datasets.
- `notebooks/`: Jupyter notebooks for exploratory data analysis and prototyping.
- `src/`: Python source code for data processing, feature engineering, and modeling.
- `dashboard/`: Application entry point for an interactive dashboard.
- `models/`: Serialized model artifacts, parameters, and related metadata.
- `reports/`: Generated reports and figures.
- `tests/`: Unit tests for the Python codebase.

## Getting started

1. Create and activate a virtual environment.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start developing data pipelines under `src/` and notebooks under `notebooks/`.
